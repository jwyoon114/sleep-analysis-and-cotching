# 달잠 · 수면 기록과 코칭

달잠은 수면 기록을 분석해 단계별 그래프, 기간 비교, 생활습관에 맞춘 조언을 제공하는 서비스입니다.

**공식 서비스** [daljam.onrender.com](https://daljam.onrender.com/)

## 휴대폰에서 이용하기

### iPhone · iPad

1. Safari에서 [달잠](https://daljam.onrender.com/)을 엽니다.
2. 공유 메뉴에서 **홈 화면에 추가**를 선택합니다. **웹 앱으로 열기**가 표시되면 켠 뒤 추가합니다.
3. Apple 건강 기록은 지원하는 수면 JSON으로 내보내 달잠의 **수면 기록 추가**에서 가져옵니다. Sleep JSON v1과 Health Export Kit JSON v2를 지원합니다. 홈 화면 웹앱은 HealthKit 직접 자동 연결을 지원하지 않습니다.

### 갤럭시 · Android

1. [달잠](https://daljam.onrender.com/)에서 **갤럭시 앱 다운로드**를 누릅니다. 운영 사이트에 이 변경이 반영되면 다운로드 고정 경로는 `/downloads/daljam-android.apk`입니다.
2. 받은 APK를 열어 설치합니다. 필요한 경우 다운로드한 브라우저에 이 앱을 설치할 권한을 허용합니다. **Android 9 이상**이 필요한 테스트 버전입니다.
3. 달잠에 로그인하고 삼성 헬스에서 Health Connect 수면 공유를 켭니다.
4. 달잠의 **건강앱 연결하기**에서 수면 읽기 권한을 허용하고 삼성 헬스를 선택합니다. 앱에서 **동의하고 연결**을 누르면 해당 출처의 최근 30일 수면 기록을 전송합니다.

## 구현 및 검증 상태

| 구분 | 내용 |
| --- | --- |
| 운영 웹 | 회원가입·로그인, 계정별 기록 저장, 수면 JSON 가져오기, 수면 단계 그래프와 기간 비교, 규칙 기반 코칭과 이력 조회 |
| 갤럭시 테스트 APK | 공식 서버 주소, Health Connect 수면 읽기, 출처 선택과 전송 동의, 서버 동기화 요청 구현. APK 서명과 합성 데이터 기반 서버 저장·계정별 접근 제한 검증 완료 |
| 갤럭시 실기기 확인 | APK 설치, 삼성 헬스 공유와 권한 화면, 실제 기록 전송, 저장된 그래프와 코칭 조회까지 확인 필요 |
| 테스트 버전 제한 | APK 직접 설치, 앱 화면에서 동기화, 인터넷 연결 필요. 휴대폰 알람과 푸시 알림은 지원하지 않음 |

공식 웹은 Next.js, FastAPI, Render PostgreSQL을 사용합니다. 규칙 기반 코칭은 외부 AI API 호출 없이 조언을 생성합니다. 수면 단계는 기기 추정치이며 조언은 의료적 진단을 제공하지 않습니다.
