# 달잠 · 수면 분석과 AI 코칭

수면 기록을 분석하고 시간별 수면 단계 그래프, 과거 기록과 개인화 AI 코칭을 제공하는 프로그램입니다.

## 최신 업데이트 · 2026년 11월 7일

- 대시보드·과거 기록·분석 직후 시간별 수면 그래프
- AI 제안 시간 불러오기와 매일 반복 취침·기상 **PC 알람**
- AI API 잔액·지출 한도·요청 속도 제한 오류를 구분하는 안내
- 아이폰·안드로이드 홈 화면 설치용 **PWA 소스**, 앱 아이콘과 설치 안내
- 오프라인 캐시에 수면 기록·API 응답을 보관하지 않는 연결 안내

휴대폰용 프로젝트는 준비했지만 **외부 공유나 서버 공개는 시작하지 않았습니다.**
휴대폰 자체 알람과 앱스토어용 APK·IPA는 포함하지 않습니다.

## 다른 Windows PC에서 달잠 웹앱 실행

1. [달잠 Windows 설치 ZIP](daljam-windows-setup.zip)을 열어 **Download raw file**로 내려받습니다.
2. [설치 안내](DALJAM_WINDOWS_README.md)에 따라 Python과 Node.js LTS를 설치합니다.
3. ZIP을 전체 압축 해제하고 **SETUP.cmd**를 두 번 클릭합니다. 첫 설치에는 인터넷 연결이 필요합니다.
4. 설치 후 바탕화면의 **달잠 웹앱 실행**을 누릅니다. 개발 도구를 직접 열 필요는 없습니다.

각 PC에서 프로그램과 서버를 실행합니다. 만든 사람의 PC가 꺼져 있어도 사용할 수 있습니다.
계정과 기록은 PC마다 따로 저장되며, 새 PC에서는 새 회원가입이 필요합니다.
기존 `.lnk` 파일은 만든 PC 전용입니다. 새 PC의 바로가기는 SETUP이 생성합니다.
이 저장소는 비공개이므로 GitHub에서 내려받으려면 저장소 접근 권한이 있어야 합니다.

## Python 소스 보기와 실행

저장소 루트의 `.py` 파일은 기존 Streamlit 프로그램과 Python API의 소스입니다.
[Python 실행 안내](PYTHON_README.md)를 따라 설치하세요.
최신 분석 직후 그래프와 과거 기록 그래프가 포함되어 있습니다.

## 휴대폰용 웹앱 프로젝트

[휴대폰 PWA 소스 ZIP](daljam-phone-pwa-source.zip)은 아이폰·안드로이드용 웹 화면과 Python 서버 소스 묶음입니다.
휴대폰에 바로 설치하는 APK가 아니며, 실제 접속·홈 화면 설치에는 별도로 접근 가능한 HTTPS 서버 주소가 필요합니다.
외부 공유 실행기와 터널 다운로드 도구를 제외한 묶음입니다.

## 알람 사용 조건

취침·기상 알람은 프로그램 서버가 실행되는 Windows PC에서 울립니다.
브라우저를 닫아도 서버가 실행 중이면 작동하지만 PC 종료·절전·서버 종료 시에는 울리지 않습니다.
기능 추가 전에 생성한 코칭에는 제안 시간이 없을 수 있어 새 코칭을 생성하거나 시간을 직접 입력합니다.

## 개인정보와 AI 코칭

API 키, 기존 계정·수면 데이터베이스, 실제 건강 파일, 백업과 로그는 포함하지 않습니다.
AI 키 없이도 수면 기록 분석과 저장, 그래프를 사용할 수 있습니다.
AI 코칭은 자신의 서버 API 키가 필요하며 별도 API 사용료가 발생합니다.
