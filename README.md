# 나의 수면 리포트

수면 기록 분석·개인화 AI 코칭 프로그램의 비공개 소스 보관소입니다.

## 다운로드와 실행

1. [전체 소스 ZIP](sleep-coach-source.zip)을 열고 Download raw file 버튼으로 다운로드합니다.
2. 압축을 풉니다. 코드·실행 도구·테스트·사용 안내 59개 파일이 폴더 구조대로 들어 있습니다.
3. 압축 안의 README.md에 있는 다른 PC에서 실행 안내를 따라 설치합니다.

## 포함 내용

- 수면 Markdown/JSON 분석 및 단계별 요약
- 회원가입·로그인·계정 편집 및 삭제
- 과거 분석·AI 코칭 조회, 휴지통·복원·영구 삭제
- 7일·30일 비교와 백업 관리
- Streamlit 웹 화면, FastAPI 서버, Windows 실행기
- PC를 켜 두고 사용하는 무료 인터넷 공유 도구
- Flutter 모바일 앱 소스(빌드된 APK는 포함하지 않음)

## 개인정보와 비용

API 키, 계정·수면 DB, 실제 건강 파일, 백업, 로그는 포함하지 않습니다. 기존 기록 백업은 별도로 관리하세요.
공유 주소는 PC가 켜져 있을 때만 접속할 수 있으며 재연결하면 바뀔 수 있습니다. OpenAI 코칭 생성에는 별도 API 사용료가 발생합니다.

ZIP 안의 source_manifest.json에는 원본 파일 검사용 SHA256 목록이 있습니다.
