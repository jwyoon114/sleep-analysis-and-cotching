# 달잠 휴대폰 앱 사용 안내

아이폰·안드로이드의 지원 브라우저에서 홈 화면에 설치하는 웹앱(PWA)입니다.
앱스토어 설치 파일은 아닙니다. 모든 제조사·구형 OS에서의 동작을 보증하지는 않으며 실제 기기 확인이 필요합니다.

## PC에서 연결 시작

1. 바탕화면 **달잠 웹앱 휴대폰 공유 실행**을 누릅니다.
2. 연결 안내 페이지가 열리면 휴대폰 카메라로 QR 코드를 스캔하거나 HTTPS 주소를 휴대폰에서 엽니다.
3. 휴대폰에서 기존 계정으로 로그인합니다. 동일한 서버 PC의 기록을 함께 사용합니다.
4. 사용을 마치려면 **달잠 웹앱 휴대폰 공유 종료**를 누릅니다. 웹앱 서버는 유지되고 휴대폰 연결만 중지됩니다.

## 휴대폰에 아이콘 추가

- 아이폰·아이패드: Safari → 공유 → 홈 화면에 추가 → ‘웹 앱으로 열기’가 표시되면 켜기 → 추가
- 안드로이드: Chrome 또는 삼성 인터넷 → 메뉴 → 앱 설치 / 홈 화면에 추가
- 앱 화면의 ‘앱 설치 안내’에서도 설치 순서를 볼 수 있습니다.
- 카카오톡 등 앱 내부 브라우저에서는 Safari·Chrome으로 다시 열어 설치하세요.

## 동작 조건

- 서버 PC·인터넷·달잠 웹앱·공유 연결이 켜져 있어야 합니다.
- 임시 공유 주소는 재연결 시 바뀔 수 있습니다. 이 경우 새 주소로 홈 화면에 다시 추가합니다.
- Cloudflare 무료 임시 연결은 개발·시연용이며 상시 고정 주소 운영과 다릅니다.
- 수면 기록·코칭·API 응답을 서비스 워커의 오프라인 캐시에 보관하지 않습니다. 연결이 끊기면 일반 안내 화면만 표시합니다.
- 로그인 세션 쿠키는 브라우저가 관리합니다. 새 주소·새 설치 환경에서는 다시 로그인할 수 있습니다.
- 취침·기상 알람은 서버 PC에서 울립니다. 휴대폰 기본 알람이나 백그라운드 푸시 알람은 구현되어 있지 않습니다.
- 기존 OpenAI API 잔액·한도 오류는 앱 설치로 해결되지 않습니다. AI 기능에는 유효한 API 설정이 필요합니다.

## 개발자 실행

```powershell
python share_phone.py --backend-project 'Python 서버 폴더'
python share_phone.py --backend-project 'Python 서버 폴더' --stop
```

공식 Cloudflare 실행 파일의 SHA256을 확인한 뒤 실행합니다. 설치되어 있지 않으면 포함된 공식 다운로드 도구를 사용합니다.
공유는 명시적으로 실행할 때만 켜집니다. 시작 메뉴 자동실행이나 방화벽·공유기 포트 개방을 추가하지 않습니다.
