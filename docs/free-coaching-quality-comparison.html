분석과 적용 범위

관찰 계산과 문장 생성을 분리했습니다. 같은 입력 방식의 최근 기록에서 날짜·겹침·시간대 조건을 확인하고, 시각 변동, 평소 입력 시각보다 반복해서 늦은 시작, 이전 평균보다 짧은 기록, 직전 기록과의 차이, 직접 입력한 카페인·만족도 중 우선 항목을 선택합니다. 최대 두 행동을 제시합니다. 45분·35분 기준은 주제를 고르는 제품 규칙이며 의학적 기준이 아닙니다.

자정은 시계의 최소 원호로 비교하며 시간대 변경·서머타임·여러 구간의 밤에는 시각 변동을 보류합니다. 실제 경과 시간과 기록 방식별 수면 시간은 구분합니다. 나이·생활습관을 미입력하면 추정하지 않습니다. MBTI 미설정은 중립적인 전달 방식을 사용합니다.

개선 대상은 현재 웹 무료 요청과 건강앱 자동 코칭입니다. 호환용 /coach의 이전 표현·분석 계약과 Premium 모델 어댑터는 보존했습니다. 수동 기록과 자동 연동 기록 모두 새 무료 엔진을 사용하지만 측정 통계에 수동 추정치를 합산하지 않습니다.

말투 polite/casual과 강도 gentle/firm/direct는 별도입니다. 존댓말을 선택한 강한 직설은 존댓말 지시문을 유지합니다. 동의는 모든 강도에서 저장되지만 거친 표현을 반드시 넣지는 않습니다. 현재 엔진은 관찰된 시각·시간 차이가 있는 강한 직설에서만 제한적으로 사용합니다. 미허용으로 바꾼 뒤 새 조언은 거친 표현을 사용하지 않으며 과거 원문은 그대로 보존합니다.
